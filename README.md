# 课时管家 · 课时管理系统

一个移动端优先的单文件 HTML 工具，可以：
- 日历排课：点击日期查看当日课程，右上角「＋」新建课程
- 学生档案：按月时间窗筛选、新增/编辑/删除学生，按学生查看全部课时
- 课程联动：输入学生姓名自动匹配或新建档案；删除学生自动联动清理其课时
- 数据本地存储（localStorage），无需后端，离线可用

## 直接打开

解压后双击 `index.html` 即可在浏览器运行（推荐 Chrome / Safari）。

> 说明：在 `file://` 协议下所有功能（新增/编辑/筛选/详情联动/统计）都正常；仅"添加到主屏幕"功能需要 HTTPS 环境，因此部署后可获得更好的移动端体验。

## 本地启动（推荐）

如果想要"添加到主屏幕"图标，最简方式：

```bash
# 在解压后的目录里运行任一命令：
python3 -m http.server 8080
# 或者
npx serve .
```

然后访问 `http://localhost:8080/`，Chrome/Safari 浏览器菜单里选择「添加到主屏幕」即可像 App 一样使用。

## 文件结构

- `index.html` — 主应用（CSS/JS 全部内嵌，单文件）
- `manifest.json` — PWA 元数据
- `sw.js` — Service Worker（离线缓存）
- `icon.png` — 应用图标

## 使用指南

### 日历页面
1. 点击任意日期 → 下方显示当天课程
2. 右上角「＋」→ 新建课程
3. 课程卡片再次点击 → 进入编辑（含删除按钮）

### 新建课程弹窗
1. **学生姓名** — 输入即查重，已存在会显示"已匹配档案"，新名字会提示"自动存入档案"
2. **上课时间** — 选择开始/结束时间到时/分，系统自动显示时长（x 小时 x 分钟）
3. **上课内容** — 自由输入

### 学生档案页面
1. **时间窗筛选** — 起止月份支持 ‹ › 切换；右上角按钮切换「单月」/「区间」
2. **右上角「＋」** — 新增学生档案（姓名、学校、年级、联系方式、课程方向）
3. **学生卡片** — 显示筛选窗口内课时数
4. **点击学生** — 进入详情，可查看完整课时列表（按月分组）、编辑或删除档案

### 删除学生
将自动删除其全部课时记录，弹窗会提示确认。

## 数据
- 数据保存在浏览器 localStorage（key = `lesson_manager_v1`）
- 同一链接不同设备数据各自独立（适合个人使用）
- 想要换设备共享数据：导出浏览器存储即可
